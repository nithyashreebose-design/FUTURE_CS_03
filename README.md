# Task 3 - API Security Risk Analysis

##Tools Used
* ReqBin
* Browser Developer Tools
* OWASP API Security Top 10
* Canva (for report design)

##What I Did
* Tested public APIs for security weaknesses
* Checked authentication and authorization controls
* Analyzed API responses, status codes, and headers
* Identified data exposure and input validation issues
* Evaluated risks using the OWASP API Security framework
* Documented findings and recommended remediation measures

##Deliverables
* API Security Risk Analysis Report (PDF uploaded in /reports folder)
* Supporting screenshots of API requests and responses
* Security findings with risk ratings and remediation steps

##Learnings
* How to assess API security posture
* How to identify broken authentication and authorization flaws
* Understanding data exposure and security misconfiguration risks
* Applying OWASP API Security Top 10 concepts
* How to communicate technical findings in a professional security report
